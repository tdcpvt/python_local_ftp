1. PROJECT CONCEPT & GOALS
--------------------------------------------------------------------------------
A custom, multi-threaded local application running inside a Termux container or desktop machine that merges a Python Flask-driven Web Management Control Dashboard with an operational data layer. 

The entire visual user interface is designed to meticulously replicate the classic desktop layout of Microsoft Windows XP Service Pack 2 (SP2), rebranded securely under the "LFT Server" identity system. It features crisp silver-blue Luna bars, high-priority system taskbars, zero-dependency inline SVG vector icons, corporate logo elements, interactive drag-and-drop window positioning, and an in-page login validator loop to avoid rendering conflicts on standard and emulated mobile-desktop browsers.

3. INVENTORY SYSTEM PERMISSION MATRIX RULES
--------------------------------------------------------------------------------
* Universal Cross-Access Matrix: Any verified user client connected across the local network can open, read, explore, and upload files into any other client's 'Public' folder partition loop.
* Private Directory Shield: Access to a 'Private' folder structure is strictly limited. Only the direct owner of that client profile account or the master 'admin' account can read or write data blocks within it. All cross-injections from unauthorized paths are explicitly blocked by an HTTP 403 error.
* Granular Deletion Constraints: Normal users have standard read/write permissions. The ability to delete an uploaded file is controlled by a 'can_delete' boolean parameter inside the 'users' object block in 'users_db.json'. This flag can only be enabled or modified by the master admin profile.
* Note & Message Isolation: Messages created via Express Notes are strictly isolated. Only the designated recipient can view the contents of a note. Senders and recipients are both granted permission to delete notes from their respective logs.

4. ACTIVE SYSTEM COMPONENT IMPLEMENTATIONS
--------------------------------------------------------------------------------
* Desktop Drag & Drop Canvas Interface (`desktop_drag.js`): Integrated mouse and touch boundary-aware position controls allowing users to drag Windows XP popup frames by their title bars and freely rearrange desktop shortcut icons across the screen canvas.
* Decoupled Express Messaging & Notes System: Integrated `notes_handler.py` and `templates/includes/notes_window.html` featuring a taskbar mail shortcut (📫) and desktop shortcut. Supports message drafting with priority flags ("Important", "Note", "Look At"), user-to-user recipient targeting, timestamp logging, and full deletion controls for both senders and receivers.
* Dynamic Network Admin Tools Window: Implemented a decoupled router (`network_admin.py`) and a 4th Windows XP popup layout block allowing the master administrator to run real-time local port scans (`free_port` range 5000-5020) and rebind the system mDNS domain loop on the fly.
* Resolved Master Admin Permissions: Overrode rigid folder isolation checks inside the explorer route parameters (`app.py`), allowing administrators to smoothly enter and read both Public and Private directories across user accounts.
* Rebranded LFT Server Logon Welcome Screen: Replaced Windows XP texts with "LFT Server" while maintaining retro design themes. Features the signature label "Tech Day's Communication" pinned to the bottom-left corner in small 12px text.
* Zero-Dependency Inline Company Logo: Integrates the company green round boat/wave emblem as a high-fidelity inline SVG component, eliminating external network dependencies and broken image icons.
* In-Page Asynchronous Login Validator: Upgraded the login pipeline via Fetch API to intercept wrong user entries, rendering an authentic warning alert box block ("Invalid username or password.") right on the canvas, eliminating redirection drops to blank error sheets.
* Decoupled Upload Engine Processor: File evaluation is offloaded out of the main server stream to `upload_handler.py`. It securely verifies extensions against whitelist schemas before initiating real file transfers to disk.
* Extensible Extension Whitelist: Supports deep structural checking for exact required file types: jpeg, jpg, png, doc, docx, xls, xlsx, ppt, pptx, pdf, txt, zip. This filter profile is stored dynamically under the JSON configuration dictionary.
* Isolated Touch-Priority Start Event: Bypasses Chrome Mobile's coordinate translation layer in "Desktop Site" mode by binding directly to the 'touchend' event loop within a modular macro file (`start_trigger.js`).
* Live Disk Quota Monitor Bars: Displays a dynamic layout progress bar mapping current total storage capacity metrics across the directory stack against an enforced limit boundary of 250 MB.

5. RESOLVED SYSTEM ISSUES (TERMUX QUICK-CHECKS)
--------------------------------------------------------------------------------
* Jinja TemplateNotFound Error for Drag Engine: Resolved HTTP 500 crash caused by evaluating `desktop_drag.js` with `{% include %}` inside `desktop.html`. Replaced with standard Flask static url loader tag `<script src="{{ url_for('static', filename='desktop_drag.js') }}"></script>`.
* Desktop mDNS Tuple String Splitting Crash: Resolved a data-type layout crash by forcing the `get_local_ip()` socket hook to extract purely the string slice (index 0), filtering out arbitrary tuple port structures.
* Chrome Desktop Mode Taskbar Coordinate Offset: Patched click failures on emulated wider displays by shifting the Start Menu popup wrapper to absolute fixed coordinates (`position: fixed !important; bottom: 42px !important;`) pushing cleanly upwards over the taskbar elements.
* False-Failure JSON Parser Crash: Patched an upload bug where standard success flags triggered error popups due to unparsed plain text streams by implementing structured JSON data returns across endpoint responses.
* Missing name="file" Attributes: Resolved an upload dropout bug by explicitly binding the 'name="file"' parameters into the HTML input forms, allowing Flask to bind files correctly to disk.
* Suspended Background Port Lock (PID 19457): Patched port occupancy bugs by tracing lingering Python execution variables using clean `ps aux` command filters and running direct termination (`kill -9 PID`) calls.
